Detector de thrashing

Pulsa Ejecutar para ver el detector en acción.

Thrashing (hiperpaginación): la RAM no alcanza para el conjunto de trabajo del proceso, casi cada acceso es un page fault y el sistema pasa más tiempo haciendo swap con el disco que ejecutando. Se detecta cuando, en los últimos Δ accesos, las páginas distintas (WSS) superan los marcos y la tasa de page faults llega al umbral. Alerta = el WSS ya no cabe pero todavía no falla tanto.

Utilización de CPU vs. marcos asignados (curva de thrashing)

Al presionar Ejecutar se calcula la utilización de CPU con 1 a 7 marcos. Los círculos rojos marcan cuántos marcos producen thrashing.
